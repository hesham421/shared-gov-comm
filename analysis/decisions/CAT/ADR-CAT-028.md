## Decision
traces: OI-12, POL-CAT-010, CAND-CAT-001
Accept A. Option B (either language) is lighter for Egyptian electronics traders but risks the Saudi requirement that a tax invoice be in Arabic. The Arabic name may contain Latin brand or model text, which covers Latin-only trade names. The citation (KSA VAT Implementing Regulations, Art. 53) is recalled and `NO-RESEARCH`. If it is wrong, the fallback is "at least one of ar, en", and POL-CAT-010 is the only artifact that changes. POL-CAT-010 rests on this dialogue resolution, not on user text, so it awaits the user's confirmation at the gate. The mandatory Arabic name takes one of the four entries allowed by POL-CAT-006.
Sources: profile language policy `ar, en`; KB §6.1.
