1. **No ADR files written.** The brief limited writes to these two files, which conflicts with the instruction to record ambiguities as ADRs. I wrote no ADR and used no new ADR number; each choice is listed in a "Derivation notes" section at the top of each file (N1–N12, F-N1–F-N9) for the review gate.
