## PHASE TEST-PLAN-BE — module scenarios

The phase holds 169 TCs, which is more than 12, so it is split into two SUBs:
- `RULE-SCENARIOS` (94): each AC whose Then names a RULE refusal, a RULE notice or a RULE-governed state transition, including the parallel-request cases of the concurrency guards (TC-CAT-200 … 205, 211, 227 … 230) and the inactive-parent matrix (TC-CAT-212), the import time limit (TC-CAT-217), the image reference and 20-image checks (TC-CAT-218) the name clash on reactivation (TC-CAT-219), the Arabic normalisation of names with digits (TC-CAT-225), the scale-prefix check of an import row (TC-CAT-226) and the label barcode of RULE-CAT-037 (TC-CAT-233, 234).
- `API-SCENARIOS` (75): endpoint-driven ACs — happy paths, reads, paging, search, events, permission, tenant isolation, optimistic lock, tenant provisioning, CAT lookup reads, reactivation of Categories, Variant attributes and values, the default-Variant moves (TC-CAT-221, 222), request consistency and updates of inactive records (TC-CAT-223), the Category change events (TC-CAT-224), the label screen's internal barcode (TC-CAT-231) and the unit of a Bundle line quantity (TC-CAT-235).
